## 3. The order

**Item 1 — init-run-measurement: run-cost rows recorded at
session-handoff's close, beside the session record (feature-to-be).**

- **Framing served:** the planned initiative
  [init-run-measurement](../initiatives/init-run-measurement.md)
  (planned, v5; a sub-initiative of init-run-efficiency; the
  authority's bet of 2026-09-08). Problem: the cost of a run is known
  only when someone reads the transcripts by hand. Outcome: every
  session close records, without a model, cost metrics for each agent
  run — step, role, minutes, context tokens, output tokens where the
  harness gives them, tool uses — beside the session record, so any
  run can be analysed on request. Measure: sessions whose close
  records the cost rows, now 0, target every session — reached only
  as far as the sibling init-process-runner's own rollout of the
  router carries it, per the architect's R2 as the bet restates it.
  Appetite: 2 hours, 50K context tokens, one working session; no
  analysis in the step itself, rows only; no measure that needs a
  model. The two decisions the bet depends on stand checked:
  [adr-2026-09-08-run-cost-artifact](../decisions/adr-2026-09-08-run-cost-artifact.md)
  (the row's home, a new artifact beside the session record, written
  only by a runtime step) and
  [adr-2026-09-08-run-cost-initiative-scope](../decisions/adr-2026-09-08-run-cost-initiative-scope.md)
  (the session-record anchor alone; reconcile-and-close and a review
  conversation's anchor are separate, later work).
- **Owning context:** none — lead-shop-internal. The ruling followed
  is the initiative's Decomposition section, the solutions architect
  role's attached ruling, screened and bet on: no Bounded Context is
  touched — the new artifact, the runtime step, and any tooling change
  sit in the lead shop's own tree; no contract exists on this branch;
  cross-context flow none. Not a cross-context item; no escalation
  applies.
- **Readiness (first untaken item):** **not ready.** No feature exists
  — the initiative's Features section reads "None yet." It waits on
