    14	# Artifact type: run-cost
    15	
    16	## Identity and ancestry
    17	
    18	- **Type:** `run-cost` — the cost rows for one session's close: one row
    19	  per step recorded on the session's anchor, naming step, role,
    20	  minutes, context tokens, output tokens, and tool uses, none of them
    21	  computed by a model. A mechanical record, never a governing
    22	  definition: nobody approves an instance, and none is amended once
    23	  written.
    24	- **Produced by:** the `write-cost-rows` step of
    25	  [session-handoff-process](../processes/session-handoff.md), a runtime
    26	  step, from the execution's bead and the harness's own usage report alone.
    27	  **Consumed by:** the authority, who reads the cost; the run-efficiency
    28	  parent initiative, whose measure the rows feed.
    29	
    30	## Required frontmatter
    31	
    32	`type: run-cost`, `id`, `session` (the path of the session record this
    33	instance sits beside), `anchor` (the `bd` work item id the rows were
    34	read from), `created`, `updated`. The field set is closed.
    35	
    36	## Required sections
    37	
    38	1. **Rows** — one table row per step the anchor records: step,
    39	   role, minutes, context tokens, output tokens, tool uses. A field the
    40	   harness's usage report does not expose for that run is blank.
    41	
    42	## Commitment (Definition of Done)
    43	
    44	An instance is done when its rows can be read without opening the
    45	session record or a transcript. **Consequence on failure:** the
    46	authority reads transcripts by hand instead, the cost this feature
    47	exists to remove.

    15	# Process: Session handoff
    16	
    17	**Purpose:** Close a conversation so later work starts from governed
    18	records alone — no memory channel, no chat summary, and no transcript as
    19	the carrier.
    20	
    21	**Guiding statement:** State crosses sessions only inside governed
    22	artifacts. A fact worth remembering has a governed home; a durable
    23	correction amends the definition it corrects, never a memory.
    24	
    25	**Outcomes:**
    26	- O1. The session record validates against its type — witnessed by the
    27	  `validate` run and the `route-validation` branches.
    28	- O2. The record and the work registry are pushed — witnessed by the
    29	  atomic `land` run.
    30	- O3. Every durable correction is filed as an amendment bead targeting
    31	  the definition it corrects, and the record only points at those beads —
    32	  witnessed by the check on `collect`.
    33	- O4. A record that cannot validate within the round cap lands anyway
    34	  with a filed defect, so the handoff never silently fails — witnessed by
    35	  the failsafe branch and `file-defect`.
    36	- O5. A session whose conversation ran tracked on a `bd` work item gets
    37	  a cost row for each step that item recorded, beside the session
    38	  record and without a model — witnessed by `write-cost-rows`.
    39	
    40	**Roles:** router (Accountable — runs the handoff when a conversation
    41	closes). The consumer is the router that next touches the work: the
    42	start drain reads the anchor before accepting it.
    43	
    44	**Scope note:** one execution closes one discovery conversation, whose anchor
    45	is a session record. Review and work conversations close through their
    46	own anchors — decisions land as changes in the artifacts they affect, work discussion lands
    47	on the work item — under the same discipline: the anchor is the only
    48	carrier. A transcript that ends mid-conversation is not a close; the
    49	conversation stays open until its anchor says otherwise. `run_anchor` is
    50	a second, distinct thing: the `bd` work item the closed conversation's
    51	own run passed through the router on, if it had one — never the session
    52	record itself. An ad hoc conversation the router never moved has none;
    53	`write-cost-rows` then writes nothing.
    54

   103	## Steps
   104	
   105	```yaml
   106	start: collect
   107	parameters: [run_anchor]
   108	result: session_record
   109	steps:
   110	  - id: collect
   111	    name: Write the session record
   112	    run-by: {role: router, execution: agent}
   113	    inputs: []
   114	    outputs: [session_record, corrections]
   115	    checks:
   116	      - corrections.all(c, c.target != "" && c.bead != "")
   117	    prompt: |
   118	      Write or update the session record: outcome first; the produced and
   119	      revised lists complete; every open thread names its next ready
   120	      action. For each durable correction met this session — a rule,
   121	      preference, or mode change that should outlive the session — file a
   122	      bead targeting the definition it amends and list the pair here. The
   123	      record points; the definition carries. Nothing goes to a memory
   124	      channel: memory writes are frozen.
   125	    next: write-cost-rows
   126	
   127	  - id: write-cost-rows
   128	    name: Write the cost rows
   129	    run-by: {execution: runtime}
   130	    inputs: [session_record, run_anchor]
   131	    outputs: [cost_artifact]
   132	    run: |
   133	      python3 basis/tools/write_cost_rows.py ${session_record.id} --anchor ${run_anchor}
   134	    next: validate
   135	
   136	  - id: validate
   137	    name: Validate the record
   138	    run-by: {execution: runtime}
   139	    inputs: [session_record]
   140	    outputs: [validation]
   141	    run: |
   142	      shop-knowledge validate ${session_record.path}
   143	    next: route-validation
   144	
   145	  - id: route-validation
   146	    name: Route on validation
   147	    run-by: {execution: runtime}
   148	    inputs: [validation, round]
   149	    branches:
   150	      - label: "success exit: record validates"
   151	        when: validation.ok
   152	        next: land
   153	      - label: "failsafe exit: round >= 3"
   154	        when: round >= 3
   155	        next: file-defect
   156	      - else: repair
   157	
   158	  - id: repair
   159	    name: Repair the record
   160	    run-by: {role: router, execution: agent}
   161	    inputs: [session_record, validation]
   162	    outputs: [session_record]
   163	    prompt: |
   164	      Repair every named violation in the validation errors. Do not
   165	      remove content to pass validation — a section the schema demands is
   166	      written, not deleted.
   167	    next: advance-round
   168	
   169	  - id: advance-round
   170	    name: Advance the round counter
   171	    run-by: {execution: runtime}
   172	    inputs: [round]
   173	    set:
   174	      round: round + 1
   175	    next: validate
   176	
   177	  - id: file-defect
   178	    name: File the validation defect
   179	    run-by: {execution: runtime}
   180	    inputs: [session_record, validation]
   181	    run: |
   182	      bd create --title "Session record failed validation at handoff: ${session_record.id}" \
   183	        --body "${validation.errors}"
   184	    next: land
   185	
   186	  - id: land
   187	    name: Land the handoff
   188	    run-by: {execution: runtime}
   189	    atomic: true
   190	    inputs: [session_record]
   191	    run: |
   192	      git add -A && git commit -m "Session handoff: ${session_record.id}"
   193	      bd dolt push
   194	      git push
   195	    next: end
   196	```

   186	def step_map(process_id: str) -> dict:
   187	    """id -> {role, execution} for every step of the named process, read
   188	    from its Steps yaml block. `unparseable` on any defect."""
   189	    for path in sorted((REPO / "basis" / "processes").glob("*.md")):
   190	        text = path.read_text()
   191	        m = re.match(r"^---\n(.*?)\n---\n", text, re.S)
   192	        if not m:
   193	            continue
   194	        try:
   195	            fm = yaml.safe_load(m.group(1))
   196	        except yaml.YAMLError:
   197	            continue
   198	        if not isinstance(fm, dict) or fm.get("id") != process_id:
   199	            continue

   201	        if len(steps_section) != 2:
   202	            fail("unparseable", f"{path}: no `## Steps` section")
   203	        block = re.search(r"```yaml\n(.*?)\n```", steps_section[1], re.S)
   204	        if not block:
   205	            fail("unparseable", f"{path}: no yaml block under `## Steps`")
   206	        try:
   207	            data = yaml.safe_load(block.group(1))
   208	        except yaml.YAMLError as exc:
   209	            fail("unparseable", f"{path}: Steps yaml does not parse: {exc}")

   261	            if defn and defn["execution"] in ("agent", "human"):

   263	                row = [step_id, defn["role"] or defn["execution"], minutes, None, None, None]
   264	                rows.append(row)

   266	            continue

   275	                router_in + router_cc + router_cr, router_out, None,
   276	            ])

   280	                        (rts, r) for step_rows in row_by_step_id.values()
   281	                        for (rts, r) in step_rows
   282	                    ]

   287	                    agent_rows_here[0][3] = sub_in + sub_cc + sub_cr
   288	                    agent_rows_here[0][4] = sub_out
   289	            segment_start = ts

   293	        "---",
   294	        "type: run-cost",

   296	        f"session: sessions/{session_id}.md",

   315	    lines.append("")
