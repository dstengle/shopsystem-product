# Experience record: variations

The one home for a per-type departure from a corpus rule, as
`consistent-not-uniform` bullet 4 allows. Read by the
[common experience guideline](../guidelines/experience-common.md)
rule 2, the [interaction fitness set](../fitness/interaction.fitness.md)
scenario 2, and every rule that says "or a recorded variation". An
entry means: for that interaction type, the rule reads as varied, for
the reason given; an unrecorded departure is a finding. This record's
evidence is the reason, so it carries no source column.
