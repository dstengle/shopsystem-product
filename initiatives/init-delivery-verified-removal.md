# Initiative: Remove the delivery-verified principle

## Framing

Originator (product authority, 2026-09-09, through the lead shop's
operational contract (lead-4kymc), split out of the discovery on
req-2026-09-09-lead-shop-builds;
req-2026-09-09-delivery-verified-amendment, section 1): "We need to
take care with delivery-verified. It could result in a lot of
bottlenecks and extra work if it is dogmatic and put in the wrong
place. The term 'running system' itself is problematic when you are
talking about libraries or non-server products."

The conversation that request was routed to overtook its ask. The
authority, 2026-09-15 (lead-vfaj4, sess-2026-09-15-a): "There is no
mechanism that would be possible to implement in the current system
that would meet the principle. This will need to be brought back when
the system is more mature." And: "I will bring it back in the future."

Problem: `delivery-verified` stands in the working principle set,
which is compiled into every session, and no mechanism implementable
in the system as it stands can meet it. Every activity therefore
carries an obligation it cannot discharge, which teaches that a MUST
in the set may be read as aspiration.

Outcome: the working set holds only obligations the system can
discharge. The bar returns when a demonstration form exists that works
in an agent shop — on the authority's own word, at their own time.

## For whom

Every shop and every session: the set is compiled into each one, so an
unmeetable statement reaches all of them. Nearest to the problem is
whoever closes work and must cite demonstration evidence that cannot
exist.

Measure: statements in the working set that no activity in the system
can discharge — now 1 principle of 10, target 0.

Interaction types: none. The change lands in compiled context and in
the definition corpus; it adds and removes no interaction.

## Appetite

One working session: the removal drafted, judged, approved, the
compiled set refreshed, and the dependents swept.

No-gos:

- **No reinstatement mechanism** — no parked request, no conditions
  recorded as a gate. The authority's decision of 2026-09-15: they
  carry the return on their own word.
- **No replacement demonstration form defined.** That no mechanism
  exists is the finding; inventing one is the future work this
  removal makes room for, not part of it.
- **The verifying observation is not promoted.** The small-change
  lane's form stands exactly as it is, in that lane alone.
- **No change to `bidirectional-conformance`'s statements** — only
  the rationale sentence naming the removed principle as its
  forward-direction flank is reworded.
- **No work reopened** that was closed under the principle.

None yet.
