## Outcome

**Mode: shaping** (intent-012 → a candidate; not yet reached — handed off). The
product authority directed genuine PM discipline: reframe, iterate, and prove the
shape before committing a bet.

**Crystallized the grounding-record form.** Across several iterations the record
converged to its definitive spine: **the question → the terms derived from it
(the audit surface a reviewer attacks first) → per-term interrogation → the
assembled set → the decision**, with a *hard link* on every included artifact
(question → term → exact command → full candidate set → explicit selection rule).
A four-persona review (technical writer, developer, project manager, English
teacher) fixed readability: a summary box, a glossary, one idea per sentence,
scannable tables, and a verified section that is a runnable `checks` block, not
prose.

**Proved the decomposition with a 5-round adversarial experiment** (a `/workflows`
run: researcher → bullshit-detector → refine-the-prompt, ×5). Result: **5/5 FAIL**,
the researcher prompt grew ~2.6K → ~25.6K chars and still failed. The trajectory
split the problem: **traceable inclusion** (no thin air) is a discipline win (the
hard-link form drove it to zero), while **complete + correct selection** (found
everything, read it right) is a tool problem prompt-hardening cannot close — the
adversary kept winning at exactly the missing-tool points (title-scan rules that
don't reproduce, no full-text/body facet, incomplete-universe claims, missed
accepted decisions, a misread axis).

**Conclusion carried into the intent (see intent-012 "Shaping status"):** you
cannot prompt your way to trustable grounding on the current tools; verifiable
selection needs **full-text/body search + populated tags + complete-enumeration**,
plus an **adversarial-verification pass**. The record *form* is a skill; the
*selection* is a tool problem.
