# Research branch

Research reports live here, away from the live system, so their bulk
never loads into a working session's context. Each report is
self-contained: question, method, findings with confidence and
sources, limitations. The live system cites a report by branch and
path; nothing here is authoritative for how the shop works — the
definitions that a report informs carry that authority.
